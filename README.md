### 📘 Overview

My research and engineering directions focus on **heterogeneous large model runtime architecture** and **autonomous agent\-based data reasoning systems**\. The core goal is to build standardized, decoupled, and schedulable LLM infrastructure, unifying local lightweight inference and cloud\-based model services to implement closed\-loop intelligent data analysis, program synthesis, and autonomous decision\-making workflows\.

The technical system covers model runtime abstraction, secure execution sandboxing, agent iterative reasoning, and end\-to\-end workflow orchestration, forming a complete technical paradigm from model scheduling to business insight generation\.

---

### ⚙️ Core Research \& Engineering Focus

- **Heterogeneous LLM Inference Architecture**
Constructed a unified model scheduling runtime to implement compatible scheduling of local GGUF inference, Ollama service inference, and cloud LLM API services, solving heterogeneous model runtime differentiation and environmental inconsistency\.

- **Decoupled Model Provider Abstraction Layer**
Designed a standardized provider isolation architecture, realizing unified parameter governance, instance caching, and runtime lifecycle management for different LLM service endpoints\.

- **Trusted Sandboxed Execution Infrastructure**
Implemented an isolated runtime environment for LLM\-generated analytical code, providing static verification, dynamic execution interception, and resource constraint control for agent synthetic programs\.

- **Closed\-Loop Iterative Data Reasoning Agent**
Built an autonomous data analysis agent system supporting automatic analytical code generation, runtime error feedback, iterative correction, and structured insight mining from original data\.
